Este modelo é composto por duas partes, um Modelo de Posse (nota referida, não encontrada nos originais) e um [Modelo de Passe](Modelo%20de%20Passe.md) 

Bola dntro da área de um jogador durante X tempo (X frames)
Podemos usar homografia ou modelo visual

Este modelo é utilizado para virar a flag de posse de uma equipa

Deve ter variável que distinga quem tem a bola 

Troca a flag numa de duas condições:
 - Detetar durante os X frames a bola na area do jogador (Modelo de Posse (nota referida, não encontrada nos originais))
 - O [Modelo de Passe](Modelo%20de%20Passe.md) detetar 2 passes bem sucedidos consecutivos da mesma equipa QUANDO esta equipa é a que NÃO estava com a posse
