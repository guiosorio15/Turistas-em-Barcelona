## Convenções

1. `[NN]` é ordem de leitura; `[00]` é sempre um índice.
2. `?` significa desconhecido. Nunca se inventam nomes, números, fontes ou resultados.
3. Toda a afirmação quantitativa tem fonte (ficheiro, paper, repositório ou medição nossa com comando).
4. Dados restritos, vídeos, tracking e derivados **nunca** entram neste repositório.
5. Cada documento diz no topo o seu estado: `vivo`, `rascunho` ou `arquivado`.
