## Resumo em seis linhas

1. Um jogo (Barça–Athletic), **199 319 frames**, uma etiqueta por frame: `H`, `A`, `D` ou `X`.
2. Corrida a **`spellF1`**; `macroF1` desempata. Nada de júri.
3. Entregamos CSV + repositório público reproduzível + documento técnico.
4. Entrega a **2026-11-17**.
5. Proibido: anotar à mão, usar dados humanos **deste** jogo, afinar nos 5 minutos públicos, submeter o que o repo não regenere.
6. Tudo o resto é permitido, incluindo modelos, tracking próprio e dados de **outros** jogos.

Fonte primária sempre em `vendor/mtah/` (cópia oficial preservada). Onde houver conflito, vale o repositório oficial, não este resumo.
